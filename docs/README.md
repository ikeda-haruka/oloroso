# Estudio Oloroso ドキュメント管理

本ディレクトリは、フラメンコスタジオ「Estudio Oloroso」WEBサイトのデザイン・設計ドキュメントを管理しています。

## 📌 タスク・進捗管理について
WEBサイトリニューアルに伴う全機能・画面・外部連携のタスク管理は、**GitHub Issues** へ完全移行して運用しています。

👉 **[GitHub Issues を確認する](https://github.com/ikeda-haruka/oloroso/issues)**

* **画面・機能タスク**: `P01-01` 〜 `P06-04`, `SYS-01` 〜 `SYS-04`（計30件）
* **外部連携・機能要件**: `INT-01` 〜 `INT-11`（計11件）
* **ラベル体系**:
  * `cat:page`（ページレイアウト・コンテンツ）
  * `cat:system`（共通コンポーネント・システム）
  * `cat:integration`（外部連携・インフラ）
  * `priority:high` / `priority:medium` / `priority:low`
  * `status:done`（実装完了済み）
